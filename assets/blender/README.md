# Idea Grove asset scripts

Every asset of the Idea Grove is original and generated by these scripts (no scans, no stock, nothing
from another MEXTY game). Outputs are listed with their library URLs in `../manifest.json`.

```bash
python3 textures.py build/tex                      # painted, tileable textures (numpy + Pillow)
python3 sounds.py build/audio                      # synthesised ambience + UI sounds (numpy + ffmpeg)
export OW_TEX=build/tex OW_OUT=build/glb
blender -b --factory-startup -P make_tree.py       # idea_tree.glb (+ hook_00..17), forest_tree.glb
blender -b --factory-startup -P make_props.py      # lantern, plaza, stall_biome/chrono/sky, telescope, boulders
blender -b --factory-startup -P make_foliage.py    # fern, flowers (4 clumps), grass_tuft
blender -b --factory-startup -P make_avatar.py     # kid_avatar.glb: rigged, idle/walk/wave/cheer, tintable materials
blender -b -P render_preview.py -- in.glb out.png [yaw] [elev]   # catalogue thumbnail (Cycles)
blender -b -P pose_preview.py -- kid_avatar.glb out_prefix       # one frame per animation
```

Built with Blender 4.2.3 LTS (portable tarball). Budgets: < 20k triangles and < 5 MB per model.
